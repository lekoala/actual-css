# Docs site

This directory contains the generated documentation pages plus the site's own
assets (docs.css, docs.js), which are edited directly.

Do not edit the generated HTML pages or assets/search-index.js directly. Edit
`docs/pages/**/*.md`, `docs/navigation.json`, `scripts/docs/**`,
`scripts/templates/docs-page.html`, `docs/site/assets/docs.css`, or
`docs/site/assets/docs.js`, then regenerate.
