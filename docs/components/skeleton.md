# Skeleton

Loading placeholder.

## Variants

- `.title`
- `.text`
- `.avatar`

## Default

Default skeleton.

```html .list
<div class="skeleton"></div>
```

## Title

Title placeholder.

```html .list
<div class="skeleton title"></div>
```

## Text

Text line placeholder.

```html .list
<div class="skeleton text"></div>
```

## Avatar

Avatar placeholder.

```html .list
<div class="skeleton avatar"></div>
```

## Accessibility

- Use `role="status"` for screen readers.
