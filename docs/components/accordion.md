# Accordion

Collapsible content sections.

## Default

Default accordion.

```html .list
<div class="accordion">
  <details open>
    <summary>First item</summary>
    <div class="accordion-body">Content here.</div>
  </details>
  <details>
    <summary>Second item</summary>
    <div class="accordion-body">More content.</div>
  </details>
</div>
```

## Accessibility

- Use `<details>` for native disclosure.
