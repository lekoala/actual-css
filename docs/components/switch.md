# Switch

Toggle switch.

## Intents

- `.primary`
- `.secondary`
- `.success`
- `.warning`
- `.danger`
- `.neutral`

## Default

Default switch.

```html .list
<label class="choice">
  <input class="switch" type="checkbox" checked>
  Enable notifications
</label>
```

## Colors

Intent colors.

```html .list
<label class="choice">
  <input class="switch primary" type="checkbox" checked>
  Primary
</label>
<label class="choice">
  <input class="switch success" type="checkbox" checked>
  Success
</label>
<label class="choice">
  <input class="switch danger" type="checkbox" checked>
  Danger
</label>
```

## Accessibility

- Switches should have an associated label.
