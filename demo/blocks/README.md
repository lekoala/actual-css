# Interface Blocks

These examples are hand-authored interface recipes for validating Actual CSS primitives in realistic app UI.

They are not a block library and they do not define new public classes. Local `block-*` styles exist only to arrange the demo page or to fill gaps that an app would normally own.

## Blocks

- `page-header` - breadcrumb, title, supporting copy, and actions.
- `compact-metrics` - six compact stats that collapse through `grid-6`.
- `table-workspace` - toolbar, filters, selectable table rows, row actions, and pagination.
- `empty-state` - recoverable empty list with a primary next step.
- `settings-panel` - form fields, switches, help text, alert, and sticky actions.
- `detail-layout` - primary content with an aside for metadata and actions.
- `notification-center` - persistent alerts and message list, without toast-first patterns.
- `auth-card` - minimal sign-in form with field semantics and secondary actions.

Open `index.html` directly from this directory, or link to it from a local demo catalog.
