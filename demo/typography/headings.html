Headings

Headings should create hierarchy without needing a large public scale.

CSS

.prose h1 {
  font-size: 2rem;
}

.prose h2 {
  font-size: 1.5rem;
}

.prose h3 {
  font-size: 1.25rem;
}

.prose h4 {
  font-size: 1.125rem;
}

Use document structure for hierarchy. Do not use heading classes as visual utilities.
