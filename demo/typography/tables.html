Tables

Long-form content can contain simple prose tables, but app data tables should use the table component.

CSS

.prose table {
  inline-size: 100%;
  border-collapse: collapse;
}

.prose th,
.prose td {
  padding: 0.5em;
  border-block-end: var(--border-width) solid var(--border);
  text-align: start;
}
