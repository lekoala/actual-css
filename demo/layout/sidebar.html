.sidebar > :first-child {
  flex-basis: var(--sidebar-size, 16rem);
  flex-grow: 1;
}

.sidebar > :last-child {
  flex-basis: 0;
  flex-grow: 999;
  min-inline-size: min(100%, var(--sidebar-content-min, 50%));
}

Tune the side width and wrapping threshold with --sidebar-size and --sidebar-content-min.
