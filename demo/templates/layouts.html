Layout reference

The canonical layout compositions, each built only with the current layout primitives. This page is a reference for what each primitive does today — and where its limits are.

1. Page header

Title on the left, actions on the right. .cluster with --cluster-justify: space-between; the row wraps into two rows when it runs out of room — no viewport decision needed.

    2. Vertical rhythm

    .stack owns the block axis: direct-child margins are reset, spacing comes from --gap. To group a few items tightly (a title and its description), nest a .stack gap-none — the outer stack keeps its rhythm between groups.

    3. Inline group

    .cluster is the inline group: action rows, tags, toolbars. Its responsiveness is the wrapping itself — it never needs a breakpoint.

    6. Fixed grid — .grid-3 alone

    As-is: .grid-3 is a fixed three-column grid at every width. Nothing collapses it without a .container-query wrapper — the three columns stay cramped on narrow viewports.

    7. Fixed grid — .grid-3 under .container-query

    The current contract: the same .grid-3 inside a .container-query collapses 3 → 2 → 1 columns as the container narrows. The behaviour depends on the wrapper, not the grid itself.

    9. Content + aside — .sidebar-layout under .container-query

    The current contract: inside a .container-query the aside appears beside the content once the container reaches 64rem, and stacks below it below that. The switch point is a container width, not a viewport width.

    10. Asymmetric 2/3 + 1/3

    --grid-columns replaces the intrinsic auto-fit template, so nothing restores collapse: the two columns stay cramped on narrow screens unless the author adds their own collapse rule. For content + aside this is usually .sidebar-layout instead.

    13. Two equivalent zones

    .switcher places two or more zones side by side when the container has room and stacks them when it does not. Lives in the optional module, not the core bundle.

    14. Avatar + text + actions

    .media for the avatar/text pair, with the actions nested inside the flexible column so they wrap under the text when the row narrows. The avatar aligns to the top (start, the default) because the content column is multi-line; centering is only for short single-line pairs.
