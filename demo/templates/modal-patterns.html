Modal patterns

Modal layouts, composed

Eight real application modals, each built from the same .modal surface and the layout primitives. The point is to see where the framework ends and where a project's own CSS begins: every rule under application CSS in this page is the smallest addition a dialog needs, and everything else is a documented primitive.

Open each pattern, then resize the window, switch theme, and toggle forced colors. The centered, hero, illustration, release and profile dialogs are the ones that carry application CSS; the confirmation, filters and picker dialogs are pure framework composition.
