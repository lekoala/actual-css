Rich composer

The Actual composer chrome around a rich editor: attachments and actions belong to the composer, never to the serialized HTML. Enter stays a paragraph; sending goes through Ctrl/Cmd+Enter or the send button. The Snippet and Mention buttons reuse the same suggestion seam as / and @.

Bridge contract

Actual maps tokens, it does not restyle the editor's internals. The bridge CSS stays in docs/demo — it is a recipe, not package API, so no actual-richtext.css ships with the framework and no widget version is pinned by it.
