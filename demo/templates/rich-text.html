Bridge contract

Actual owns the visual language; Squire owns the document. The bridge CSS stays in docs/demo — it is a recipe, not package API, so no actual-richtext.css ships with the framework and no widget version is pinned by it. The same contract would hold for any headless editing engine. 

.actual-richtext .rich-editor {
  min-block-size: 10rem;
  padding-inline: var(--control-pad-x);
  border: var(--border-width) solid var(--form-invalid-border, var(--control-border));
  border-radius: var(--radius);
  background: var(--control-bg);
}

/* Attached toolbar: a light bar sharing the surface's top edge.
   Borderless buttons on the bar; pressed state from .btn. */
.actual-richtext .rich-toolbar {
  align-items: center;
  margin-block-end: calc(var(--space-10) * -1);
  padding: var(--space-10) var(--space-20);
  border: var(--border-width) solid var(--form-invalid-border, var(--border));
  border-block-end-width: 0;
  border-radius: var(--radius) var(--radius) 0 0;
  background: var(--surface-subtle);
}

.actual-richtext .rich-editor {
  border-block-start-width: 0;
  border-start-start-radius: 0;
  border-start-end-radius: 0;
}

.actual-richtext .rich-editor:focus-within {
  outline: var(--focus-ring-width) solid var(--form-invalid-border, var(--focus));
  outline-offset: calc(var(--focus-ring-width) * -1);
}
