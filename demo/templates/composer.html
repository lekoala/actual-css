Composer × Actual CSS

A native <textarea> inside an Actual surface, with an actions row around it. The textarea stays native — form value, IME, undo, mobile, validation — while the surface owns border, focus, and states. Switch themes: the composer follows the tokens, including material.

    Enter contract

    The only JavaScript the composer needs. Plain Enter is a newline; composition sessions (IME) never send. 

    input.addEventListener("keydown", (event) => {
  if (event.key !== "Enter" || event.isComposing) return;
  if (event.ctrlKey || event.metaKey) {
    event.preventDefault();
    form.requestSubmit();
  }
  // Plain Enter falls through: the textarea inserts a newline.
});
