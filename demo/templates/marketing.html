Why teams switch

Three primitives. No new mental model.

Layout, components, and tokens compose the way plain HTML already wants to.

Layout primitives

.stack, .cluster, and .center cover the compositions you reach for every day, without a utility class for every property.

One theme contract

Every component reads from the same token surface. Write one theme that matches your brand instead of overriding seventeen.

Semantic by default

Components style real HTML elements and ARIA patterns first, so accessibility isn't a separate pass at the end.

The method

Quiet defaults, earned complexity

  1. 1
    Start with plain HTML.

    The baseline styles native elements so a form or a table already looks right before a single class is added.

  2. 2
    Add structure with primitives.

    Reach for .stack, .cluster, and .grid before inventing a one-off layout.

  3. 3
    Theme at the token layer.

    Colors, radii, and spacing flow from a small set of tokens — change the theme, not the components.
